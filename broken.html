About This Assignment

Break It, Fix It & Validate It

This assignment challenges students to identify HTML errors, correct them and validate their work.

First, inspect the broken HTML document.

Next, correct the errors and validate the fixed document.

Assignment Objectives

  • Identify common HTML errors
  • Understand correct HTML structure
  • Improve website accessibility
  • Validate HTML using the W3C Nu HTML Checker
